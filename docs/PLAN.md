# 第一版实施计划

## 使用目标

用户点击网页稿纸上的位置即可输入文字，输入后立即看到纸面上的占格、换行和分页结果，用于后续手写誊抄。
重点保证位置预测和编辑操作可靠；字体用于辅助阅读，不承诺复现个人笔迹。

## 范围

| 功能 | 要求 |
| --- | --- |
| 纸面编辑 | 连续输入、中文组词、粘贴、选区、删除、撤销及重做 |
| 稿纸参数 | 横排，默认 20 行 × 20 格；可调整行列数、格子大小和行间距 |
| 区块格式 | 标题居中、称呼顶格、正文缩进、落款右对齐 |
| 标点与混排 | 可选择行末标点占格策略；处理引号、括号、省略号、破折号及数字 |
| 分页 | 容量不足时自动续页，编辑后实时重新计算 |
| 统计 | 字符数、总页数、光标所在页、行、格 |
| 保存 | 浏览器本地自动保存正文和设置，支持恢复 |
| 输出 | 打印稿纸，通过浏览器保存 PDF |

不纳入第一版：页末文字提示、誊抄进度、已抄页锁定。

## 排版原则

- 区分字符数与占格情况：缩进、段尾留白和标点处理都会影响分页。
- 排版结果明确记录每个排版单元对应的源文本范围及页、行、格位置。
- 排版引擎不修改原文，不擅自替换标点或补删文字。
- 段首缩进是布局属性，避免向正文自动写入空格造成重复缩进。
- 中文输入法组合期间保持输入稳定，提交文字后再同步最终布局。
- 保留明确的输入偏移与视觉位置映射，支持点击定位及跨行、跨页选择。
- 缩放不改变排版；相同正文与设置始终生成相同的行和页。
- 标点规则集中配置，明确支持的数字、英文及特殊符号占格方式。

## 实施顺序

### 1. 排版引擎

- [ ] 定义文档、区块、稿纸设置和排版结果的数据结构。
- [ ] 实现分格、段首缩进、段尾留白、换行和自动分页。
- [ ] 为段落、标点、混排和页边界建立有代表性的测试。

### 2. 稿纸与输入

- [ ] 构建稿纸、文字、光标和选区显示。
- [ ] 使用统一文本输入机制支持中文输入法，避免每格独立输入。
- [ ] 实现鼠标定位、键盘移动、编辑和撤销重做。

### 3. 格式与规则

- [ ] 增加标题、称呼、正文和落款区块。
- [ ] 增加纸张设置、标点策略及统计显示。
- [ ] 验证边界处插入、删除和跨页编辑后的重排。

### 4. 保存与输出

- [ ] 实现本地保存、恢复及草稿备份。
- [ ] 实现打印样式、物理纸张尺寸和分页。
- [ ] 检查预览与打印输出是否一致。

## 验收要求

1. 中文输入、整段粘贴、跨页删除和撤销操作正常。
2. 汉字、标点和数字在支持的规则下正确占格，规则调整不改变原文。
3. 标题、称呼、正文和落款的空格与占行计入布局。
4. 测试标点恰好落在行首、行尾和页尾时的处理。
5. 同样的正文和设置在刷新及缩放前后保持相同分页。
6. 保存后可恢复正文、区块格式及稿纸设置。
7. 打印和 PDF 中的分行、分页与屏幕预览一致。

测试素材使用虚构文稿；真实个人文稿仅在本地用于人工对照，不提交到仓库。
