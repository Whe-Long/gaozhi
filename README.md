# 稿纸 Gaozhi

在网页稿纸上直接输入文字，实时预览誊抄到纸上时的占格、换行和分页效果。

## 项目状态

项目已建立，当前提交包含功能范围和实施计划，应用代码尚未开始开发。

## 第一版目标

- 直接在稿纸上输入和编辑，支持中文输入法、粘贴、选择、删除和撤销。
- 默认使用横排 20 行 × 20 格稿纸，可调整行列数、格子大小和行间距。
- 所有段落从每行第一格排起；段首缩进、标题居中、落款靠右等留白由使用者自行输入空格。
- 点击任意空白格子即可在该格书写，空出的格子自动补全角空格。
- 根据所选规则处理标点占格、行首行尾限制和自动分页。
- 显示字符数、总页数及光标所在页、行、格。
- 在浏览器本地保存正文及设置，刷新后恢复草稿。
- 支持打印稿纸，并通过浏览器保存为 PDF。

第一版不包含页末文字提示、誊抄进度和已抄页锁定。

## 技术方向

计划采用 React、TypeScript 和 CSS Grid，第一版在浏览器本地运行。
排版模块独立于界面，文字内容与纸面位置分别管理。缩放和字体调整不改变字符所属的格子。

详细范围、实施顺序和验收要求见 [项目计划](docs/PLAN.md)。

## 数据边界

仓库只保存项目代码与通用测试素材，不提交个人申请书、扫描件或其他真实用户文稿。
