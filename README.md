# 稿纸 Gaozhi

在网页稿纸上直接写字，实时看到誊抄到纸上时每个字落在哪一格、在哪里换行和分页。

## 功能

- 点击稿纸任意位置即可输入，支持中文输入法、粘贴、选择、删除、撤销和重做。
- 点击段尾或下方的空白格子，可以直接在该格书写，空出的格子自动补全角空格。
- 所有段落从每行第一格排起；段首缩进、标题居中、落款靠右等留白由使用者自行输入空格。
- 标点可选择行末悬挂或严格占格；省略号、破折号占两格，半角数字和字母可两个一格。
- 稿纸默认 20 × 20，可调整行列数、格子大小、行间距、预览字体和格线颜色。
- 底部显示字数、总页数和光标所在的页、行、格。
- 自动保存在当前浏览器；可导出 JSON 备份或纯文字，也可重新导入。
- 可打印或保存为 PDF，每张稿纸占一页 A4。

## 使用

需要 Node.js 20.19 或 22.12 以上版本。

```bash
npm install
npm run dev
```

然后在浏览器打开 <http://127.0.0.1:5173>。

打印时选择 A4、100% 缩放，并关闭浏览器页眉页脚。

## 开发

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器，修改代码后页面自动更新 |
| `npm run build` | 类型检查并打包到 `dist/` |
| `npm test` | 运行单元测试 |
| `npm run test:coverage` | 运行单元测试并检查覆盖率（不低于 80%） |
| `npm run test:e2e` | 运行 Playwright 端到端测试 |

第一次运行端到端测试前，需要先执行 `npx playwright install chromium` 下载测试用浏览器。

```
src/
  layout.ts    排版引擎：把文字排进格子、处理标点和分页、点击定位
  model.ts     文稿与纸张设置的数据结构和校验
  storage.ts   读取本地草稿，读取失败时保留原文
  App.tsx      界面与编辑交互
tests/e2e/     端到端测试
```

## 数据

文稿只保存在当前浏览器的本地存储里，不会上传。换电脑或清理浏览器数据前，请先导出 JSON 备份。

仓库只保存代码和虚构的测试文字，不提交真实的个人文稿。
